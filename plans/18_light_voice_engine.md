## Задача одной строкой

У владельца **уже выбран голос** — `voice/out/candidates/JARVIS/espeech_bystree.mp3` (движок
ESpeech-TTS-1 RL-V2). Проблема не в звуке, а в ресурсах. Нужно, чтобы голос ЭТОГО класса качества
звучал, не конкурируя с основной моделью за видеопамять.

## Почему план появился — что уже отвергнуто замером

| путь | вердикт | чем доказано |
|---|---|---|
| Silero (резидентный, CPU, 0.1 с/фраза) | ⛔ владелец: «отвратительно. разные голоса. НЕПРИЕМЛИМО» | вердикт владельца, канон |
| **Piper VITS medium, дообученный на Вихрове** | ⛔ владелец: «**отвратительно**», оба темпа | вердикт + замер: **23.7 М параметров генератора против ~330 М** у ESpeech/F5, 22.05 кГц против 24. Разрыв в 14 раз обучением не покрывается |
| ужать контекст qwen с 98K до 32K ради VRAM | ⛔ тупик | освободило всего **330 МБ**: память ест не KV-кеш, а веса |

**Числа-ограничители, все измерены:** с загруженной основной моделью занято 15 356 МБ из 16 303,
свободно **~950 МБ**. ESpeech в бою просит **3 150 МБ**. Не влезает — это и есть корень задачи.

## Три трека — заказаны владельцем все три

### Трек А. Замерить ESpeech/F5 на CPU  ⭐ приоритет

**Гипотеза:** если уже одобренный движок идёт на процессоре быстрее реального времени, задача
исчезает целиком — владелец получает ровно тот голос, который выбрал, и он не занимает VRAM
вовсе. Никто этого не мерил: все замеры RTF (0.167–0.197) сняты **на GPU**.

- [ ] Замерить RTF ESpeech на CPU на фразах кастинга (фикс. тексты `homeworks/03`).
- [ ] Замерить пик RAM и время холодного старта (для решения «резидентный демон или разовый вызов»).
- [ ] То же для F5-TTS_RUSSIAN (голос JOI выбран на нём).
- [ ] Вывод: годится для ЖИВОГО разговора (RTF < 1) или только для подготовленной речи.

⚠️ **Мерить только на свободном CPU.** Обучение держит 6 воркеров загрузки данных — замер рядом
с ним измерит конкуренцию за процессор, а не движок (класс EXP-0033).

## Определение готовности плана

Владелец слышит голос **выбранного им класса качества** в живом разговоре, и этот голос не
отбирает у основной модели столько VRAM, чтобы она перестала помещаться. Мерится: вердикт
владельца по звуку + `nvidia-smi` при работающей LLM + RTF на реальной фразе.

## Правила, которые этот план обязан соблюдать

- **Тексты кастинга фиксированы** (`homeworks/03`) — иначе сравниваются тексты, а не движки.
- **Выдача по форме владельца:** один файл на вариант, все пять текстов подряд, кусочки удалены,
  папки по кандидатам, громкость выровнена к −14 LUFS.
- **Агент не судит красоту** (EXP-0031): его работа кончается макетом, вердикт даёт владелец.
- **Тяжёлое — по одному** (уронённый файл подкачки, вечер 2026-07-30).
