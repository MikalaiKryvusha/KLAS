## Наблюдение

Ревизия нашла ЧЕТЫРЕ дрейфа, каждый из класса, за который проект уже платил, и каждый ловится
механической проверкой за секунды:

| Дрейф | Инцидент-прецедент | Механическая проверка |
|---|---|---|
| Рабочие копии 2 `.bat` с LF при `attr eol=crlf` | баг 01 (LF ломает cmd) | `git ls-files --eol \| grep 'eol=crlf.*w/lf'` |
| Пин движка в манифесте b9538 при бое b10167 | bugs/05 | сверка `deploy.manifest.json.tag` с `llama-server.exe --version` |
| Транскрипт голоса затрекан в git | инциденты 07-03, 07-18, правило .gitignore:99 | скан staged-файлов по маскам звука/ключей/секретов |
| Моджибейк CP1251 в шаблоне конфига | bugs/08 | греп по сигнатуре `Р[ЎЂћѕ]` в текстовых файлах git |

## Предложение

`node tools/hygiene-check.mjs` (или блок в `health-check.ps1`) с этими четырьмя проверками,
вызываемый из `/pause` и `/release` (и вручную). Красный = стоп паузы/релиза, как kaif:check.
Расширяемый список — новые инциденты добавляют строку, а не новый инструмент.

Смежные хвосты той же природы (владелец решает, делать ли):
- запинить docker-образы (`caddy:latest` и др. — любой `pull` тащит неизвестную версию;
  homepage уже ломала проект сменой поведения, баг 03) + мигрировать deprecated `basicauth` →
  `basic_auth` в Caddyfile ДО того, как её удалят из caddy;
- healthcheck'и всем 4 сервисам compose (зависший kiwix висит «Up» бесконечно);
- решение по funnel-хосту в git: он публикуется в 10+ файлах при политике «хост вне git»
  (см. `researches/19`, вопрос владельцу).
