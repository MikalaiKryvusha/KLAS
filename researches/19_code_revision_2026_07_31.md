# Research 19 — Ревизия кода после слабых моделей (2026-07-31)

> Заказ владельца дословно: *«разработкой KLAS занимались слабые модели. Стоит проверить после
> них код на адекватность, позакрывать дыры, которые они оставили, помочь им… чем больше
> руководств, багов, идей будет оставлено после ревизии и анализа, тем лучше — в назидание
> слабым моделям»*. Исполнено Claude Fable 5 за ночную сессию 01:53–~03:00.

## 1. Метод (переиспользуемый — см. EXP-0041)

- **Объём:** 70 файлов кода в `tools/` (~450 КБ: .mjs, .py, .ps1, .sh, .bat) + конфиги
  (docker-compose, Caddyfile, манифесты, .gitignore/.gitattributes) + гигиена git-истории.
- **5 параллельных ревизоров по зонам:** Python-голос · JS/sh-голос · голосовые скрипты корня ·
  инфраструктура (deploy/install/klas/бенчи/lib) · конфиги+гигиена. Каждому выдан список УЖЕ
  ОПЛАЧЕННЫХ классов граблей проекта и правило «нет цитаты кода — нет находки».
- **Личная верификация каждой существенной находки** до фикса: краши — репро (файлом в WSL),
  логика — чтением названных строк, гигиена — командами (`git ls-files --eol`, hex-дампы).
- Существующие самопроверки прогнаны ДО правок (всё зелёное: kaif:check 52+108, guard 7/7,
  text_norm PASS, ref_pair 4/4) — и это само по себе находка: **охранники, поставленные после
  прошлых пожаров, живы; дыры были там, куда охранников ещё не ставили.**

**Счёт:** ~55 заявленных находок → ~45 подтверждено → 40+ закрыто тремя коммитами
(`d815684` голос · `b46e137` инфраструктура · `28c00f6` гигиена), остальное — открытый баг
`bugs/22` + идеи 15/16 + вопросы владельцу (§5).

## 2. Что закрыто (подробности в bugs/19–21)

| Класс | Самое показательное |
|---|---|
| **Краши живого рта** | «Файл занял 1024.5 МБ» ронял normalize() IndexError — ассистент молча пропускал реплику; даты читались «шестьминус семьминус» (`bugs/19`) |
| **Воскресшие дефекты** | охранник кириллицы в voice-say глушил ответы-числа на боевом TTS-пути ядра — bugs/06 вернулся, потому что слой нормализации вынесли, а старую проверку у потребителя не сняли |
| **Бумажные охранники** | сторож диска умирал от set -e при первом сбое df (защита от инцидента ext4 не работала); CPU-стенд «прятал» GPU через setdefault и печатал «ЗАМЕР НЕВЕРЕН» не останавливаясь; пустой корпус проходил охранника Piper; roundtrip давал 100% при 9 отказах из 10 (`bugs/19`) |
| **Тихие потери в тракте** | SSE-строка, разрезанная границей чанка, выпадала из речи; spawn без 'error' ронял процесс сырым стеком; TOCTOU замка динамиков; оборванные закачки оставляли вечный битый .pt (`bugs/20`) |
| **Деплой врал об успехе** | манифест пинил движок b9538, не умеющий тул-коллы основной модели — свежий клон получал нерабочее ядро; health-check всегда exit 0; экран «установлен и работает!» после провала; --with-kaif мёртв с рождения (нет импорта) (`bugs/21`) |
| **Гигиена** | транскрипт голоса актрисы в публичном git; docker.sock у контейнера за funnel без пользы; моджибейк в шаблоне конфига каждой новой установки; 2 автозапускных .bat с LF в рабочей копии; дыры .gitignore (`bugs/21`) |

## 3. Что осталось открытым (и почему не починено молча)

- **`bugs/22` — судьи бенчей мягче, чем заявляют** (nearNum засчитывает число в любом месте
  ответа; слепнущий датчик churn-probe; `hear()` бенча путает свою поломку с тишиной). Правка
  судей меняет ШКАЛУ — чинить одним коммитом с перемером всех моделей, а тяжёлые прогоны
  владелец отложил на завтра вечер.
- **Мёртвый код под `TRANSLIT_MODE='full'`:** ветка английских числительных в silero_daemon
  недостижима (normalize разворачивает все цифры по-русски раньше), флаг `--voice-en` в
  voice-talk фактически ничему не служит. Не трогал: это вопрос ДИЗАЙНА двуязычия, а он
  завязан на выбор мультиязычного движка (трек В), который решается прослушкой CosyVoice.
- **T4 судит звук по `spoken`** (выходу собственного нормализатора) — регрессия нормализации
  для него невидима. Осознанный компромисс; второй слой сверки — кандидат при следующей
  работе над бенчем.
- **Идеи 15/16** (дедуп общих модулей; сторож гигиены) — ждут одобрения владельца.
- `-ss` до `-i` в нарезке корпуса (граница клипа может съесть начало слова на VBR-mp3),
  несвежие файлы прошлого прогона в склейке compare-ways, FIFO без id в tts-daemon,
  «leaderboard» с сомнительным HF-эндпоинтом, winget-идемпотентность при несвежем PATH —
  мелочи, зафиксированы здесь; чинить по мере касания этих файлов.

## 4. Что выглядит здоровым (чтобы следующая ревизия не перекапывала)

- **Кодировочный контракт Node↔Python** выдержан системно: reconfigure(utf-8) во всех
  сайдкарах, канарейка с побуквенной сверкой, все open() с encoding — уроки bugs/08 вшиты.
- **Охранники с двусторонними фикстурами** (turn-verdict, ref_pair, piper-dataset-guard) —
  добротная архитектура «проверь охранника раньше, чем жизнь».
- **Секреты:** полный греп 190 коммитов — история ЧИСТА (оба старых инцидента вычищены,
  новых нет; боевые ключи живут только вне git).
- **Порты согласованы по всему тракту** (compose ↔ Caddyfile ↔ bat ↔ services.yaml ↔ klas.ps1).
- `.gitattributes` корректен; все .ps1 — UTF-8 с BOM; openclaw-chain-bench — образцовое
  судейство (случайные токены + проверка диска).
