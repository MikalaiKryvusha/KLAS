## 1. Итог одной строкой

**Портрет масштабируется.** KLAS — самый большой продукт из четырёх (экосистема: мастер
установки, LLM-стек из шести моделей, веб-часть, голосовой тракт, удалённый доступ), и регистр
«кодекс» вместил его целиком: 10 нумерованных разделов × 2 языка, 5 таблиц, ни одного вопроса
владельцу по стилю. Стоп-паттерны § 8 дали ноль срабатываний с ПЕРВОГО прохода — после чтения
портрета рука ставится сама, докрутка не понадобилась.

## 2. Метод (для воспроизводимости)

5 корпусных агентов разведки по зонам (установка · стек · использование · голос · видение;
каждый факт с evidence «файл:строка», старый README объявлен подозреваемым) → текст одним пером
по портрету → 4 состязательных проверяющих (факты §1–4, §5–8, §9–10, паритет RU/EN + стиль по
анти-портрету) → 13 правок. Это ровно ваша оркестровка «аналитики → синтез → критик», применённая
не к построению портрета, а к письму по нему.

## 3. Новое, чего нет в отчёте 01

### 3.1. «В работе ≠ роадмап» — жанр выдержал продукт в движении

У KLAS незакрытый эпик (голосовой ассистент: активация по имени, голоса персон, мультиязычный
движок). Соблазн — вернуть роадмап-таблицу с 🔧. Решение, которое легло в регистр: незавершённое
живёт в ДВУХ домах — «§ 9.3. Что в работе» (только измеренное настоящее: «готовые детекторы
отвергнуты замером — 3/6 и 0/10») и «§ 10. Ограничения текущей версии» (симптом для
пользователя: «активация по имени отсутствует — диалог по нажатию клавиши»). Будущее время в
обоих домах запрещено, кроме одной констатирующей связки («ввод мультиязычного движка снимет
транслитерацию»). Кандидат в мануальный профиль: **незавершённое описывается измеренным
настоящим, не обещанием.**

### 3.2. Перевывод из кода: счёт 6:0 на СВЕЖЕМ документе, включая баг продукта

README KLAS был не «устаревшим фродом», а месячной свежести документом, который регулярно
освежали, — и перевывод всё равно поймал шесть расхождений. Три показательных:

- **EN-половина противоречила RU-половине внутри одного файла:** EN описывала снятую схему
  («switches Russian↔English inside one reply») — в бою транслитерация одним диктором. Две
  половины дрейфуют независимо; механическая проверка паритета чисел RU↔EN (у нас — отдельным
  агентом, ноль расхождений после правок) стоит включения в методику рядом с перевыводом.
- **«~8 с на ход» без оговорки** — верно только для прогретой сессии; первый ход новой сессии
  до ~50 с. В мануале М9 (псевдоточность) работает зеркально игровой книге: числа обязаны быть
  ИЗМЕРЕННЫМИ и с честным разбросом, а не средними.
- **Перевывод нашёл дефект самого продукта:** «анонимная установка» мастера вызывает
  анонимизатор без `--apply` — то есть репетицию, которая ничего не обезличивает. Заведён
  `bugs/23`. Вывод сильнее, чем у KPOT-сессии: README-проход с перевыводом — это дешёвый АУДИТ
  продукта, а не только текста.

### 3.3. Дыра портрета: граница «публичное/приватное»

Портрет учит КАК писать, но молчит о том, ЧТО не переносится в публичный документ. При
переписке README по стилю агент честно сохранил бы: имена дикторов — доноров голосов персон,
реальный funnel-хост владельца, содержимое секрет-файлов. Этот фильтр пришлось держать вне
портрета (в README вошли только имена файлов-хранилищ вида `caddy/PASSWORD.local.txt` и
плейсхолдер `<ваша-машина>.ts.net`). Предложение: пункт в чек-лист § 7 — **«проход публичности»:
персональные данные третьих лиц, реальные хосты и секреты в публичный документ не попадают;
допускаются только имена файлов, где они хранятся.**

### 3.4. Подтверждения на новом материале

- **К0.2 (канон таблиц)** держит и технику: «Таблица N — Название» одинаково хорошо несёт модели
  с контекстами, точки входа с защитой и смету скачивания.
- **«Границы применения» (1.2)** — снова лучший дом анти-обещаний («облачные и платные подписки
  не используются»); подтверждаю § 3 отчёта 01.
- **Л8 (тёплая рамка ✦)** прожила все четыре README: кот-талисман и подпись владельца пережили
  смену жанра без единого возражения владельца — метка «врождённое» верна.
- **К9 (карантин кавычками)** легализует единственную метафору документа: «спит, пока не
  позовут» — закавычена, одна на документ, рядом стоит число (300 секунд простоя).
