# interviews/decisions — архив решений владельца

Здесь лежит **машиночитаемая половина** ответов владельца. Человекочитаемая половина живёт там же,
где вопрос, — в самом документе `interviews/` или `homeworks/`.

Это НЕ вторая правда: **md — источник, всё в этой папке — производное** (инвариант I1 регламента
`/owner-reviews`). Ответ владельца записывается контуром `tools/review.mjs` сразу в **три места**
(инвариант I2), и вот они:

| # | Куда | Зачем именно туда |
|---|---|---|
| 1 | обратно в исходный `.md` | его читает следующая сессия агента с пустым контекстом — она в эту папку не заглядывает |
| 2 | `<путь__документа>.decision.json` рядом | машинная проверка перед отправкой чего-либо наружу (гейт `checkApproval`) |
| 3 | `archive/<документ>--<время>.json` | копия, которую никогда не перезаписывают: именно она делает архив читаемым месяцы спустя |

## Правила

- **Имя файла решения производно от ПУТИ документа**, а не от одного имени файла: вопросы в KLAS
  живут в двух директориях (`interviews/` и `homeworks/`), и общий файл затирал бы чужое решение.
  `interviews/interview_010_always_on.md` → `interviews__interview_010_always_on.decision.json`.
- **`by` и `at` обязательны.** `by` проставляет сервер контура (параметр `--by`), а не спрашивает у
  владельца: на проекте владелец ровно один, и спрашивать его имя каждый раз — трение без выгоды.
  Убран ВОПРОС, а не ЗАПИСЬ — архив решений без «кто решил и когда» нечитаем.
- **Руками здесь не правят.** Расхождение с md чинится перезаписью через контур, а не редактором.
- `queue.json` — очередь накопления для автономных циклов (инвариант I7): цикл паркует документ сюда
  и идёт дальше, а владельца зовут ОДИН раз на всю пачку (`node tools/review.mjs batch`).

## Команды

```
node tools/review.mjs list                      что ждёт владельца прямо сейчас
node tools/review.mjs open <документ.md>         страница с ответом в один клик
node tools/review.mjs queue <документ.md>        отложить в пачку, не блокируя цикл
node tools/review.mjs batch                      одна страница «накопилось N»
npm run owner:questions                          охранник очереди владельца
npm run guard:reviews                            ворота сдачи контура (пилот + живой браузер)
```

Полный разбор — `plans/24_owner_reviews_contour.md`; регламент — `.claude/skills/owner-reviews/SKILL.md`.
